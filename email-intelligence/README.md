# مركز استخبارات البريد الإلكتروني

واجهة عربية تجمع روابط موثوقة لفحص ظهور البريد في التسريبات ومراجعة أمان الحساب.

## طريقة الاستخدام
1. أدخل البريد الإلكتروني مرة واحدة في الصفحة.
2. أكّد أنك تملك البريد أو لديك إذن بفحصه.
3. اضغط «جهّز البحث في كل المصادر».
4. افتح المصادر المطلوبة، وانسخ البريد والصقه بنفسك في كل موقع.

## المصادر وحدودها
- Have I Been Pwned: قاعدة بيانات تسريبات عامة.
- Mozilla Monitor: يستخدم بيانات Have I Been Pwned، لذا قد تتكرر النتائج.
- EXPERTE.de: يستخدم قاعدة Have I Been Pwned ويعرض أوصافاً بالألمانية.
- Leak Checker بجامعة بون: خدمة جامعية ألمانية بقاعدة بيانات وإجراءات مستقلة؛ راجع سياسة الخصوصية قبل الاستخدام.
- Cybernews وBitdefender وF-Secure: خدمات فحص من مزودين مستقلين؛ نطاق البيانات وطرق العرض تختلف.
- Google Security Checkup: مراجعة أمان حساب Google وليست قاعدة تسريبات عامة.
- NCSC Email Security Check: يفحص إعدادات نطاق البريد مثل SPF وDKIM وDMARC، وليس تسريب عنوان شخصي.

## الخصوصية
- لا تُرسل الصفحة عنوان البريد تلقائياً إلى أي مصدر.
- لا توجد قاعدة بيانات أو تخزين لعناوين البريد في المشروع.
- النسخ إلى الحافظة يتم فقط بعد ضغط المستخدم على زر النسخ.
- لا يجمع المشروع كلمات المرور أو رموز التحقق أو ملفات تعريف الارتباط.

## ملاحظة مهمة
لا توجد خدمة واحدة تحتوي جميع التسريبات. قد تستخدم بعض المصادر قواعد بيانات متشابهة، ولا يمكن دمج نتائجها تلقائياً في تقرير موحّد دون تكاملات رسمية وصلاحيات مناسبة. عدم ظهور نتيجة لا يضمن عدم حدوث تسريب.
