# مركز استخبارات البريد الإلكتروني

مشروع عربي بالكامل (RTL) لفحص البريد الإلكتروني في بيانات التسريبات المعروفة، مع روابط إلى مصادر فحص وأمان إضافية.

## المتطلبات
- Node.js 18 أو أحدث
- مفتاح API من Have I Been Pwned لاستخدام واجهة فحص التسريبات

## التشغيل
1. نفّذ: `npm install`
2. انسخ `.env.example` إلى `.env`.
3. ضع مفتاح الخدمة في المتغير `HIBP_API_KEY`.
4. شغّل: `npm start`
5. افتح `http://localhost:3000`

## النشر
ارفع المشروع إلى خدمة استضافة تدعم Node.js، واضبط متغير البيئة `HIBP_API_KEY` في إعدادات الخادم. لا تضع المفتاح داخل ملفات الواجهة أو المستودع.

## الخصوصية
- لا توجد قاعدة بيانات ولا تخزين لعناوين البريد.
- لا تُرسل مفاتيح API إلى المتصفح.
- لا يجمع المشروع كلمات المرور أو رموز التحقق أو ملفات تعريف الارتباط.
- يتطلب تأكيد ملكية البريد أو وجود إذن قبل الفحص.
- يعرض أسماء الحوادث وتواريخها وفئات البيانات المعلنة فقط.

## حدود التغطية
الفحص المباشر يعتمد على واجهة Have I Been Pwned ويتطلب مفتاح API صالحاً. روابط Mozilla Monitor وGoogle Security Checkup تفتح خدماتها الرسمية ولا تعني أنها تُفحص آلياً داخل هذا الموقع. لا توجد قاعدة بيانات واحدة تشمل كل التسريبات.
