# مركز استخبارات البريد الإلكتروني

مشروع عربي بالكامل (RTL) لفحص البريد الإلكتروني في بيانات التسريبات المعروفة، مع روابط إلى مصادر فحص وأمان إضافية.

## المتطلبات
- Node.js 18 أو أحدث
- لا يلزم مفتاح API؛ زر الفحص يفتح موقع Have I Been Pwned الرسمي لتدخل البريد هناك بنفسك

## التشغيل
1. نفّذ: `npm install`
2. شغّل: `npm start`
3. افتح `http://localhost:3000`

## النشر
ارفع المشروع إلى خدمة استضافة تدعم Node.js. لا توجد حاجة إلى مفتاح API لهذا النمط من العمل.

## الخصوصية
- لا توجد قاعدة بيانات ولا تخزين لعناوين البريد.
- لا تُرسل مفاتيح API إلى المتصفح.
- لا يجمع المشروع كلمات المرور أو رموز التحقق أو ملفات تعريف الارتباط.
- يتطلب تأكيد ملكية البريد أو وجود إذن قبل الفحص.
- يعرض أسماء الحوادث وتواريخها وفئات البيانات المعلنة فقط.

## حدود التغطية
زر الفحص يفتح موقع Have I Been Pwned الرسمي؛ يجب على المستخدم إدخال البريد بنفسه هناك. لا يجري الموقع فحصاً آلياً ولا يرسل البريد إلى المصدر. روابط Mozilla Monitor وGoogle Security Checkup تفتح خدماتها الرسمية أيضاً. لا توجد قاعدة بيانات واحدة تشمل كل التسريبات.
